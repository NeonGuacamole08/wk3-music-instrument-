 Electrosmith_Daisy_Seed_Rev4 as your microcontroller 
 2 Adafruit MPR121 Breakout boards that I downloaded from https://www.snapeda.com/parts/1982/Adafruit+Industries/view-part/?ref=snap 
 2 AudioJack3 
 and a Barrel_Jack_Switch. For the wiring of these, please follow the images below :

Use "A" to choose symbols like the microcontrollers 
Use "P" for power symbols like GND or 3.3V
Use "L" to label portions

## The PCB
<img width="402" height="288" alt="image" src="https://github.com/user-attachments/assets/53298953-00b8-4cc4-8b71-d875f77ae7e1" />

Make sure to route all the blue lines. 
Design the shape of your PCB using edge cuts

To insert a drawing as I did, 
Click on Image Converter in KiCad
<img width="843" height="458" alt="image" src="https://github.com/user-attachments/assets/60b8ed13-fd6b-486b-aa35-46f5314b4cdc" />
From there, you will end up here:
<img width="946" height="504" alt="image" src="https://github.com/user-attachments/assets/e23d04e1-5060-42d2-9252-11f0eca0327c" />


From the file menu, upload the image that you want to use (Make sure to use an image that has a lot of contrast) 
Now, since we are putting our designs on the PCB, select 

<img width="164" height="84" alt="image" src="https://github.com/user-attachments/assets/0f95c069-ca40-4db2-abd8-d2a88da5fbf0" />
and export to clipboard. You can then go back to your PCB and press CTRL+V to paste your image. 


We are done!!!!
